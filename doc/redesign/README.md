# Redesign comps

Static HTML for the paper-and-ink proposal in [`../minimalist-redesign.md`](../minimalist-redesign.md).

Open [`mockups/index.html`](mockups/index.html) in a browser, or from the repo root:

```bash
python3 -m http.server 4173 --directory doc/redesign/mockups
```

Then visit `http://127.0.0.1:4173/`.

These files are not served by Rails and are not part of the production asset pipeline.
